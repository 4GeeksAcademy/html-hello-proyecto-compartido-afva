# Sistema de diseño — MAISON NOVA

## Estado

Identidad provisional aprobada para el prototipo académico. Se aplicará de forma coherente en las cinco vistas.

## Marca

- **Nombre:** MAISON NOVA.
- **Logo:** logotipo tipográfico con el texto «MAISON NOVA».
- **Estilo:** minimalista, editorial y contemporáneo.
- **Idioma:** español.
- **Tipografía:** sans-serif.

## Paleta

| Nombre | Color | Uso previsto |
| --- | --- | --- |
| Blanco | `#FFFFFF` | Fondo principal |
| Negro | `#171717` | Texto y elementos de énfasis |

## Diseño

- Enfoque mobile-first, adaptable a móvil, tablet y escritorio.
- Fotografías de producto destacadas cuando haya recursos aprobados.
- Usar HTML5 semántico y Tailwind CSS para la presentación.
- No añadir JavaScript personalizado, frameworks, backend ni dependencias adicionales.

## Navegación compartida

- El logo textual «MAISON NOVA» enlaza a `index.html`.
- «Colección» enlaza a `catalog.html`.
- «Carrito» enlaza a `cart.html`.
- «Mi cuenta» es solo un elemento visual, sin funcionalidad.
- La búsqueda es visual y no ejecuta búsquedas dinámicas.
